# Cloud Computing Concepts Reflection

Cloud computing has become a significant part of modern technology, and I use cloud-based services almost every day without realizing it. Through this course, I learned that cloud computing is more than just online storage—it provides services and applications that make communication, collaboration, and productivity easier. Understanding cloud service models and deployment models has helped me appreciate how these technologies support both individuals and organizations.

## 1. Cloud Services I Use

The cloud services that I use most often are **Google Drive**, **Canva**, and **GCash**. These applications allow me to store files, create school projects, and perform online financial transactions anytime and anywhere with an internet connection.

## 2. Identify the Models

Google Drive is classified as **Software as a Service (SaaS)** because it provides file storage and document management through a web browser without requiring users to manage any hardware or software. It uses the **Public Cloud** deployment model since it is available to anyone with a Google account.

Canva is also a **Software as a Service (SaaS)** application because it offers cloud-based graphic design tools that users can access online. It is considered a **Public Cloud** service because it is accessible to the general public through the internet.

GCash is another example of **Software as a Service (SaaS)** because it delivers digital payment and financial services through a mobile application. It also operates on the **Public Cloud**, allowing millions of users to securely access their accounts and complete transactions online.

## 3. Git & GitHub for Cloud Projects

Version control is an important part of cloud computing because it helps developers manage project changes efficiently. Git records every update made to files, making it possible to track modifications and recover previous versions if mistakes occur. GitHub builds on this by providing a platform where team members can work together, create separate branches for new features, review each other's work, and merge changes safely. These tools reduce conflicts, improve collaboration, and help ensure that cloud projects remain organized, reliable, and easier to maintain throughout the development process.
